This directory is for hosting Terms & Conditions audio files for each language and user type.

Example filenames:
- farmer-terms-en.mp3
- farmer-terms-ta.mp3
- farmer-terms-hi.mp3
- farmer-terms-te.mp3
- customer-terms-en.mp3
- customer-terms-ta.mp3
- customer-terms-hi.mp3
- customer-terms-te.mp3

Place the appropriate audio files here to enable language-specific audio playback for the Terms & Conditions sections.
